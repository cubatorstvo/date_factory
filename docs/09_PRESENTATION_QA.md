# 09 — Презентация, game feel и матрица приёмки

> Каждое значимое действие должно быть подготовлено, показано, озвучено, завершено и оставить последствие.

Временные 3D-модели допустимы. Стандартный UI, мгновенный спавн, пустые коробки, системы «только кнопкой», финал без постановки — нет.

Токены палитры/шрифтов: [ART_DIRECTION.md](ART_DIRECTION.md).

---

## Художественное направление
Ранняя часть: бытовая, тёплая, чуть дешёвая.  
Средняя: яркая, брендированная личная корпорация.  
Поздняя: стерильная роскошь, повторяющиеся образы героя, странная отлаженность.  
Все UI одной игры — не набор случайных панелей.

## HUD
Только нужное: деньги, ⭐, **целостность легенды**, текущая цель, interact hint, срочный кризис.  
Bond конкретной девушки и производственные KPI — не постоянно на экране.

## Телефон
Личный пульт, не debug-меню: контакты, журнал наблюдений, расписание, отношения, цели, инфраструктура, Twitch, быстрые приоритеты. Свой стиль, open/close анимация.

## Терминалы
Крупные системы на местах: лаборатория, маршруты, гардероб, подарки, PR, центр легенды.

## Попапы (минимум 4 типа)
Обычное уведомление · предупреждение · крупное открытие · решение с последствиями — разные форма, motion, звук, приоритет.

## Анимация UI
Мягкое появление, реакция кнопок, анимация чисел, отдельные презентации: черта / девушка / стадия / дубль.  
Запрещено: мгновенное крупное окно, одинаковая анимация ошибки и награды, вечная пульсация всего.

## SFX (полный набор, даже временный)
UI · экономика · мир (шаги, двери, лифт, лаборатория, авария) · свидания · акценты крупных открытий.  
Частые звуки — вариации pitch/громкости.

## Постановка свидания / дубля
Приход → жест → диалог → уход.  
Первый дубль: полная сцена капсулы + осмотр + решение. Последующие — сокращённо, не спавн.

## Мир в простое
Сотрудники ходят, подарки едут, индикаторы мигают, дубли по маршрутам — иллюзия системы без полной симуляции жизни.

## Настройки (минимум)
Громкости · чувствительность · инверсия · FOV · head bob · camera shake · окно/полный · качество · размер текста · субтитры. Сохраняются.

## Запрещённые прототипные сокращения
Стандартный шрифт как основной · одно серое окно на всё · спавн вместо прихода · кризис текстом «решить» · производство только таймером · пустая коробка с терминалом · один звук покупки = «аудио готово» · стадия только числом · debug-подписи · «будет позже» · финал без сцены · нет сохранения/обучения.

## Матрица приёмки (проверять в запущенной игре)

### 1. Пользовательский путь
- [ ] Главное меню; новая игра; продолжить; пауза/настройки
- [ ] Первый час понятен без дизайн-дока
- [ ] 6 стадий обычным прохождением; финал; титры; постгейм
- [ ] Нет обязательных debug-команд

### 2. Ручное свидание
- [ ] Физическая подготовка хотя бы первого
- [ ] Приход через дверь/лифт; не спавн сидя
- [ ] Наблюдение-факт до реплики; 3 разные интерпретации
- [ ] Гипотеза от выбора; 2× подтверждение → черта
- [ ] Ошибка не выдаёт правильный ответ бесплатно
- [ ] Знание и bond считаются отдельно; уход физический

### 3. Авто
- [ ] Использует знания; малоизученная рискованнее
- [ ] Режимы осторожный/стандарт/риск
- [ ] Видно в зале; ошибка может дать кризис

### 4. Девушки / 100%
- [ ] Обычные + уникальные; тиры не только гринд
- [ ] 100% → орбита, бонус, присутствие, позднее событие

### 5–6. Дубли и дефекты
- [ ] Лаборатория-проект; сцена; осмотр; часы; движение; память
- [ ] Одобрить / доработка / утиль / условно
- [ ] ≥1 дефект каждого типа; пропуск → событие; исправление возможно
- [ ] Приёмка позже автоматизируется, не исчезает

### 7. Легенда и скандал
- [ ] Раздельные ресурсы; дубли бьют легенду; кризис = событие
- [ ] Нет упоминаний дублей до появления

### 8. FPS
- [ ] Физические действия; маршруты; кризисы с бегом; мир не мёртв
- [ ] Телефон не заменяет мир

### 9. Стадии
- [ ] Глаголы 1–6; переходы меняют мир; стадия 4 = создание+приёмка

### 10. Twitch
- [ ] Работает без чата; ники на массовых сущностях; уникалки авторские

### 11–12. UI / SFX / feel
- [ ] Нестандартный шрифт; единая система; 4 типа попапов
- [ ] Звуки UI/экономики/мира/свиданий/лаборатории; мягкая камера

### 13–14. Финал и прогон
- [ ] Условия ясны; Алгоритм прибывает; знания+дубли+легенда+кризис+ручное свидание
- [ ] Неудачу можно исправить; полный прогон до титров; сейвы на ≥3 стадиях
