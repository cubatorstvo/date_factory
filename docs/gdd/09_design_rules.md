# 51. Критерий новой механики

Новая механика нужна только если она выполняет хотя бы несколько задач:

- создаёт понятный смешной выбор;
- использует одну из четырёх характеристик;
- поддерживает девушку и систему тегов;
- поддерживает мужскую линию Авторитета;
- меняет физический мир;
- создаёт продаваемую сцену;
- помогает эскалации;
- переиспользуется без большого объёма новой технологии.

Механика не нужна, если она:

- создаёт ещё одну постоянную шкалу;
- требует сложного менеджмента;
- повторяет уже существующий тип решения;
- скрывает успех за случайным процентом;
- нужна только ради реализма;
- создаёт технически дорогую симуляцию, которую игрок почти не замечает.

# 52. Открытые вопросы

## 52.1. Читаемость основной черты

Достаточны ли вместе:

- фиксированная ситуация знакомства;
- внешний вид;
- начальная фраза;
- анимация прихода;
- реакция на приветствие?

Нужно проверить на незнакомых игроках.

## 52.2. Название финальной внеземной цели

Рабочее имя «Последняя» фиксирует функцию персонажа, но не является обязательным финальным названием.

Нужно найти имя или титул, который:

- звучит серьёзно;
- не похож на generic fantasy;
- не выглядит как AI-термин;
- не требует объяснения;
- работает как кульминация именно свиданий.

## 52.3. Пассивный денежный поток

Нужно отдельно определить точный момент, когда шахтная зарплата перестаёт требовать ручного получения и становится частично или полностью пассивной.

## 52.4. Число обычных девушек

Количество обычных девушек определяется производственным объёмом.

Главное требование: четыре основные и четыре дополнительные черты должны появляться достаточно рано, чтобы игрок успел понять систему до медийной перегрузки.

# 53. Итоговая формула игры

Ранняя и средняя игра:

> Найди девушку → прочитай сигналы → получи номер → пройди свидание → пойми её черту → добери отношения до +5 → получи Опытность и Балл прокачки → усили героя.

Параллельно:

> Найди самца → получи право на вызов → пройди простое состязание → получи Авторитет → повысь зарплатный уровень → получи Деньги.

Поздняя игра:

> Создавай клонов → дели их между работой и свиданиями → увеличивай Деньги/мин и Свидания/мин → масштабируй систему → охвати Землю → отправляйся на последнее внеземное свидание.

Это и есть целевая структура DATE FACTORY.
