# DATE FACTORY — Master GDD 2.0

**Статус:** целевой мастер-дизайн 2.0  
**Назначение:** единый источник истины для концепции, содержания и игровых правил  
**Источник:** пользовательский документ `DATE_FACTORY_MASTER_GDD_RU`  
**Полный текст одним файлом:** [`gdd/MASTER_GDD_FULL.md`](gdd/MASTER_GDD_FULL.md)

## Приоритет

Этот документ **полностью заменяет** прежнее целевое описание игры и все старые дизайн-документы при любых противоречиях.

Порядок разрешения конфликтов:

```text
docs/MASTER_GDD.md (+ docs/gdd/*)
>
explicit latest user instruction
>
per-module implementation spec (когда выдана)
>
docs/TECH_PLAN.md (+ docs/tech/*)   ← только порядок/границы/зависимости
>
new project code
>
legacy donor documentation/code
```

## Что не входит в Master GDD

- технический план переделки существующего проекта;
- архитектура кода;
- миграции данных;
- последовательность реализации.

Поверхностный технический план модулей: [`TECH_PLAN.md`](TECH_PLAN.md).  
Он **не** заменяет отдельную итоговую спецификацию реализации каждого модуля.

Legacy prototype (`../date_factory_legacy`, branch `legacy-v1`) — только read-only donor реализаций, **не** источник продуктовых требований.
