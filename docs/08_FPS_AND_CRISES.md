# 08 — FPS-мир и пространственные кризисы

## Зачем FPS
Не декоративная камера между меню. Игрок готовит, носит предметы, встречает, видит сигналы, наблюдает дублей, бегает между процессами, чинит сбои, ощущает рост масштаба ногами.

Любая система из телефона должна иметь хотя бы одно физическое проявление.

## Движение
Плавный старт/стоп, лёгкий head bob, отдельный бег, мягкое приземление, шаги по зонам, лёгкое движение предмета в руках.  
Сильная постоянная тряска запрещена. Head bob / camera shake — в настройках.

## Действия по стадиям (сжато)
| Стадия | FPS-смысл |
|--------|-----------|
| 1 Квартира | Телефон, шкаф, подарок на стол, встреча, уборка |
| 2 Популярный | Несколько комнат, срочная доставка, выбор между задачами |
| 3 Штаб | Терминалы, персонал, залы, первые логистические сбои |
| 4 Второй Я | Сканирование, капсула, осмотр, параллель |
| 5 Фабрика | Линии, блокировка зон, подмена дубля, кризисы легенды |
| 6 Орбита | Мегамашина, масштаб, финальный кризис |

## Зоны мира (компактные, связанные)
1. Квартира (сохраняется как начало)  
2. Городские места (хаб/отдельные локации: кафе, парк, кино, фитнес, магазины, ресторан)  
3. Операционный штаб  
4. Особняк (залы, жилая часть орбит, лаборатория, техкоридоры, PR)  
5. Фабрика (подарки, гардероб, синхронизация, QA, кризисный центр)  
6. Орбитальный сектор (финальный зал, мегамашина, центр легенды)

Не нужен бесшовный открытый город.

## Приход и уход персонажей
**Запрещён** мгновенный спавн уже сидящей девушки.

Приход: уведомление → дверь/лифт → вход → имя → жест → путь к месту → посадка → только потом диалог.  
Уход: реакция → встаёт → подарок → выход или жилая часть → пространство в обычный режим.  
Персонал: приход + представление роли + рабочая точка.  
Дубль: только лаборатория / шлюз / линия — не спавн у терминала.

## Кризис
См. структуру в [05_EVENTS.md](05_EVENTS.md). Ритм: рано редко → поздно цепочки; после тяжёлого — пауза спокойствия.

## Участие орбит
После 100%: маршрут/точка, редкие перемещения, помощь в кризисах, личное пространство, наряд, участие в финале. Без полной симуляции жизни.

## Финальный FPS-сценарий (якорь)
Запуск мегамашины → волны → массовые свидания → сбои → порядок устранения → блок зала → дефектный дубль к Алгоритму → перехват → помощь орбиты → финальный подарок → прибытие → ручное свидание → синхронизация → титры.  
Достаточно долго для кульминации, не отдельный экшен.

## Twitch в мире
Ники на табличках подарков, именах менеджеров, брендах одежды, партиях дублей, журналистах. Ценность — причинно-следственная шутка в пространстве, не только лог.
