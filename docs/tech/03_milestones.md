# 4. Крупные контрольные точки

## MILESTONE A — Technical Skeleton

Готовы MODULE 00–05.

Результат:

- чистый проект;
- FPS;
- Game State;
- data layer;
- NPC framework;
- прокачка.

---

## MILESTONE B — Core Gameplay Prototype

Готовы MODULE 06–10.

Результат:

- можно встретить самца и соревноваться;
- можно найти девушку;
- можно получить номер;
- можно пройти полноценное системное свидание;
- можно завершить отношения и получить Опытность.

Это первая обязательная проверка: интересны ли две главные игровые системы сами по себе.

---

## MILESTONE C — Early Game Vertical Slice

Готовы MODULE 11–14 для первых стадий.

Результат:

- квартира;
- город;
- сюжетные цели;
- шахта;
- несколько девушек;
- несколько соперников;
- связанный ранний игровой цикл.

Это первая версия, которую нужно проходить как настоящую игру, а не тест систем.

---

## MILESTONE D — Full Manual Game

Готовы MODULE 14–16.

Результат:

- вся ручная часть;
- медийный рост;
- перегрузка свиданиями;
- готовый переход к клонам.

---

## MILESTONE E — Incremental Endgame

Готовы MODULE 17–20.

Результат:

- первый клон;
- управление массовыми клонами;
- физическая ранняя визуализация;
- переход к большим числам;
- мировой масштаб.

---

## MILESTONE F — Complete Game

Готов MODULE 21 и весь сюжет от старта до концовки.

После этого запрещено добавлять крупные новые механики.

## MILESTONE G — Release Candidate

Готовы MODULE 22–28.
