# DATE FACTORY — Cursor workflow

Короткая схема для одного разработчика. Без автоматической оркестрации и без отдельного QA-агента.

## Основной агент

Обычные технические задачи — в свежем Cursor chat на:

`Cursor Grok 4.5 High Fast` (`cursor-grok-4.5-high-fast`)

Grok сам исследует нужный фрагмент, реализует и делает headless-проверки.

## GPT — отдельный консультант

`GPT 5.6 Sol` не участвует в постоянном техническом цикле.

Используй отдельный свежий chat с GPT только для:

- сложного геймдизайна;
- спорного архитектурного решения;
- редкого независимого аудита (цель + короткий diff + спорные пункты).

Результат GPT передай в новый Grok-чат как вход для реализации.

## Команды

### `/inspect-task`

Короткий read-only разбор: как работает сейчас, ключевые файлы, вероятная причина, минимальный план, риски.

### `/implement-task`

Реализация текущей задачи + headless проверки + короткий ручной чек-лист.

## Цикл обычной задачи

1. Открой новый chat.
2. Выбери Grok High Fast.
3. Дай конкретную задачу или `/implement-task`.
4. Прочитай короткий отчёт и чек-лист.
5. Пройди 3–8 пунктов в игре.
6. Сообщи конкретные проблемы в том же чате.

Статус до твоей проверки: `IMPLEMENTED — MANUAL CHECK REQUIRED`.

## Headless-first

Агент проверяет parser/runtime/headless без захвата фокуса.

Оконный Godot — только с твоего разрешения, когда нужен визуал.

## Ручная приёмка

Ты оцениваешь визуал, ощущения и player flow.

Агент не ставит визуальный PASS и не запускает `df-qa-worker`.

## Формат финального ответа агента

1. Что изменено (глазами игрока)
2. Файлы
3. Технически проверено
4. Проверь вручную (3–8 шагов)
5. Ограничения

## Один scope на chat

Один chat = одна крупная задача.

Новая крупная задача → новый chat.

Не читай все `docs/release/**` и старые milestone-доки автоматически. Бери один релевантный фрагмент только если задача про этот этап.

## Субагенты

По умолчанию не используются.

Опционально: `df-researcher` (read-only, Grok High Fast) — по явной просьбе или перед рискованным многосистемным изменением.

Старые workers (`df-gameplay/scene/asset/content/qa`) отключены; архив: `docs/archive/cursor-orchestrator-v1/`.

## Release docs

`docs/release/**` остаются на месте как аудит/план релиза.

Не загружай их пачкой на мелкую правку. `HANDOFF_TO_GROK.md` — исторический план, не автозапуск workers.
