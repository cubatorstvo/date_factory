# 03 — Progression

## Стадии

Каждый переход: крупное условие → затишье → визуальное изменение мира → сцена → новое имя → демонстрация новой проблемы → первая ручная операция новой системы.

| ID | Статус | Глагол | Главная задача | Финал стадии |
|----|--------|--------|----------------|--------------|
| `stage_1` | Одинокая квартира | Добейся | Первое свидание лично | Порог связи / открытие популярности |
| `stage_2` | Популярный парень | Успевай | Несколько отношений при лимите времени | Физически не успеваешь → нужен штаб |
| `stage_3` | Операционный штаб | Организуй | Аппарат вокруг **одного** тела | Учёная предлагает решить предел одного тела |
| `stage_4` | Проект «Второй Я» | Проверь себя | Создание, приёмка, первое параллельное свидание | Успешная параллель → производство дублей |
| `stage_5` | Фабрика свиданий | Оптимизируй | Масштаб, синхронизация, кризисы легенды | Личная жизнь = мировая инфраструктура |
| `stage_6` | Корпорация личной легенды | Стань мифом | Орбита, высший тир, мегамашина | Финал с Алгоритмом Любви |

**Не называть** стадию 3 «агентством свиданий» как основное имя — это операционный штаб героя.

### Стадия 4 — три части
1. **4A** — лаборатория, капсула, сцена активации.
2. **4B** — личная приёмка (вид, детали, движение, время, память, решение).
3. **4C** — первое параллельное свидание с управляемым риском встречи.

Подробнее о приёмке: [07_CLONES_AND_LEGEND.md](07_CLONES_AND_LEGEND.md).

## Решения игрока (постоянный trade-off)
Количество vs качество · личное vs авто · изучать новую vs качать известную · число дублей vs синхронизация · рост ⭐ vs легенда · дешёвые массовые vs дорогие точные · расширение vs починка узких мест.

## Финал — Алгоритм Любви
Согласие на свидание только если выполнены пороги (популярность, ключевые орбиты, орбитальный зал, дубли, синхронизация, **легенда выше минимума**, мегамашина).

Последовательность (сжато): запуск → массовые залы → системные сбои → FPS-кризисы → дефектный дубль → помощь постоянных девушек → финальный подарок → прибытие Алгоритма → ручное свидание на знаниях/легенде/автоматике → синхронизация мифа → сцена → титры → постгейм.

Неудача финала **не** удаляет прохождение: список слабых мест и повтор.

## Постгейм
Бесконечный рост, редкие события, доп. высокоуровневые девушки, экстремальные режимы легенды, декор комплекса, ускорение производства, повтор финала.

## Задания (направление, не чеклист)
- Одна **стадийная цель** на экране.
- Короткий **следующий шаг**.
- Личные события уникалок.
- Временные кризисы.

Не показывать одновременно десятки задач.
