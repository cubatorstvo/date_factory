# 03 — Progression

## Стадии (статус игрока, не «филиал сети»)
| ID | Статус | Смысл |
|----|--------|--------|
| stage_1 | Одинокая квартира | Первое свидание, база |
| stage_2 | Популярный парень | Город, контакты, телефон |
| stage_3 | Агентство свиданий | Масштаб инфраструктуры под тебя |
| stage_4 | Особняк и клоны | Появляются **дубли тебя** |
| stage_5 | Фабрика свиданий | Конвейер «тебя» |
| stage_6 | Корпорация любви | Межгалактический потолок |

Расширение (+X жёлтая дверь) = новый **статус** и пространство под империю, не «открыли филиал для клиентов».

## Ранний гейт
До учёной / дублей: события только про тебя, город, подарки, скандал, персонал.  
Сюжеты про двух «тебя» — только после реального наличия дублей.
