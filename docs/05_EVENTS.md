# 05 — Events algorithm

## Когда можно кинуть событие
`EventsAPI` разрешает ролл только если:
1. Нет активного ручного свидания (`dating.active_manual` пуст)
2. Не открыты date UI / phone / pause
3. Нет уже активного события
4. Стадия ≥ требования события
5. Выполнены `requires` карточки события

## Поля `requires` (примеры)
- `min_stage` — минимальный номер стадии  
- `clones_min` — сколько дублей уже создано  
- `needs_scientist` — знакомство с учёной (доступ к дублям)  
- `needs_staff` — есть нанятый персонал  
- `needs_automation` — уровень автолинии  

## Запрет
Не показывать сюжеты про дублей, пока `Game.clones.clones.size() == 0`.  
Не формулировать выбор «назначить клона клиентке».

## После выбора
Окно закрывается синхронно; мышь возвращается только если нет других оверлеев.
