# 05 — Events и кризисы

## Когда можно кинуть событие (код сейчас)
`EventsAPI` разрешает ролл только если:
1. Нет активного ручного свидания
2. Не открыты date UI / phone / pause
3. Нет уже активного события
4. Стадия ≥ требования
5. Выполнены `requires` карточки

### Поля `requires`
- `min_stage`, `clones_min`, `needs_scientist`, `needs_staff`, `needs_automation`
- **Цель:** также пороги легенды, наличие орбиты конкретной девушки, лаборатория, и т.д.

### Запрет
Не показывать сюжеты про дублей, пока дублей нет.  
Не формулировать «назначить клона клиентке».

## Целевые категории пространственных событий

| Категория | Примеры |
|-----------|---------|
| Логистика | Подарок не в тот зал, два свидания на один стол, лифт занят |
| Дубли | Два «ты» в коридоре, часы, неверный образ, зависание, уход с маршрута |
| Девушки | Пришла раньше, сменила место, пошла искать героя, чужой подарок |
| Публичность | Журналист, стрим, фото в опасной зоне, спонсор |
| Техника | Свет, дверь, синхронизация, конвейер, брак партии |
| Личные | Проверка обещания, конфликт орбит, «только лично, без дубля» |

## Структура короткого кризиса
1. Ясный сигнал  
2. Понятная угроза  
3. Время или нарастающее последствие  
4. 2–4 решения  
5. Физическая задача  
6. Результат в мире  
7. Влияние на деньги / ⭐ / связь / скандал / **легенду**

Пример: два «тебя» в коридоре — задержать лифт / закрыть дверь / перенаправить / отвлечь лично.

## Ритм
- Ранний: редкие, обучающие, легко чинятся.
- Средний: чаще, иногда два связанных сбоя, выбор приоритета.
- Поздний: цепочки; интенсивность растёт при низкой легенде.
- После тяжёлого кризиса — период спокойной работы.

## Гейтинг по стейту (цель)
- Нет дублей → нет событий двойников.
- Нет стримерши → нет трансляционных кризисов.
- Нет лаборатории → нет брака партии.
- Нет орбиты → девушка не «живёт в комплексе».
- Черта не подтверждена → дубль не может «забыть подтверждённую черту».
- Twitch выкл → нет событий, требующих реального чата.

## Минимальный объём (каталог)
≥6 логистика, ≥8 дубли, ≥6 девушки, ≥4 публичность, ≥5 техника, по 1 позднему на уникалку, ≥3 кризиса легенды, 1 финальный многоступенчатый.
