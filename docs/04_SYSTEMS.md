# 04 — Systems (кратко)

Как системы обслуживают фантазию «один альфа».

| Система | Роль |
|---------|------|
| Player FPS | Ты лично ходишь, смотришь, взаимодействуешь |
| Dating (manual) | Личное внимание = качество и лор «настоящий ты» |
| Dating (auto) | Дубли закрывают слоты; для девушек это всё ты |
| Clones | Копии игрока; усталость/ошибки = риск мифа |
| Girls / City | Контакты и worthiness — кто достоин твоего времени |
| Phone | Пульт империи: анкеты, апгрейды, дубли, статы |
| Facility | Комнаты/места как декорации статуса |
| Staff | Автоматизация подготовки, не «официанты для клиенток» |
| Events | Инциденты легенды; гейтятся по стейту |
| Economy | Деньги / ⭐ / скандал / внимание — ресурсы легенды |
| Quests | Туториал и толчки к следующей стадии |

Код: `autoload/game.gd` + `modules/*`, UI в `scenes/ui/*`, мир в `scenes/world/*`.
