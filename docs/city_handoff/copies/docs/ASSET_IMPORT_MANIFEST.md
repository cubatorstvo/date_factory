# ASSET_IMPORT_MANIFEST — DATE FACTORY

## 1. Цель этапа

Этот этап не посвящён художественному полишу, свету, эффектам и финальному UI.  
Цель этапа:

1. импортировать в проект только выбранные ассеты;
2. избежать дублей и мусора;
3. создать чистую структуру ресурсов;
4. привести основные материалы к совместимому базовому виду;
5. подготовить игровые сцены для дальнейшего visual pass;
6. собрать рабочий вертикальный срез:
   - квартира;
   - кусок улицы;
   - ресторан;
   - лаборатория клонов;
   - фабрика свиданий.

На этом этапе не нужно:
- делать финальный арт;
- делать сложную цветокоррекцию;
- делать финальный UI;
- делать полный полиш всех сцен;
- импортировать весь архив целиком без разбора.

---

## 2. Общий художественный курс

Базовый стиль проекта:

**Stylized semi-low-poly absurd romance-industrial sim**

Ключевые признаки:
- стилизованное окружение;
- чистые формы;
- умеренная детализация;
- без фотореализма;
- без реалистичных PBR-настроек;
- с понятной читаемостью в FPS;
- с возможностью дальнейшего визуального полиша через свет, материалы и эффекты.

## 5. Форматы импорта

Для каждого ассета использовать только одну выбранную версию.

Приоритет:

1. GLB
2. glTF
3. FBX
4. OBJ
5. BLEND, только если это действительно лучший вариант

Не хранить в проекте:
- сразу все форматы одного и того же объекта;
- Unity и Unreal-экспорты;
- demo projects;
- readme-копии;
- лишние thumbnails.

Если нужны исходные файлы вне проекта — оставить их в исходной папке assets, но не тащить в репозиторий.

---

## 6. Что обязательно исключить

Не импортировать в проект:

- демо-сцены паков;
- рекламные изображения;
- readme-файлы, не нужные проекту;
- лишние preview;
- format duplicates;
- Unity project files;
- Unreal project files;
- скриншоты паков;
- все ZIP-архивы;
- UI паки на этом этапе;
- звуки и музыку на этом этапе, если задача только по 3D;
- оружие и шутерный мусор из sci-fi набора;
- животные и экзотический декор, если они не нужны текущим сценам.

На этом этапе не нужен финальный шейдинг, но нужна базовая совместимость.
