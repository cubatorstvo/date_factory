# DATE FACTORY — бриф для обсуждения

Коротко: **абсурдная FPS-симуляция одного мужчины, который масштабирует себя до межгалактического альфы**; девушки всегда думают, что встречаются с одним и тем же человеком.

Индекс: [README.md](README.md).

---

## 1. Одна фраза

Начни с одного неловкого свидания, создай армию собственных дублей и убеди всю галактику, что идеальный мужчина существует только в одном экземпляре.

## 2. Жанр и тон

- **Жанр:** одиночная 3D FPS-инкременталка: свидания по наблюдению + автоматизация + инфраструктура + пространственные кризисы.
- **Четыре слоя тона:** бытовая неловкость → деловая оптимизация личной жизни → лёгкий корпоративный ужас → абсурдный космический масштаб.
- **Не это:** серьёзная романтика, менеджер клуба/ресторана, HR чужих работников, «агентство для клиенток».
- **UI/голос:** второе лицо («ты», «твой дубль»).

## 3. Жёсткие правила лора

1. Один объект желания — ты.
2. Дубли = ты (не товар, не персонал на выбор).
3. Девушки не заказывают и не знают про производственную систему.
4. Риск — обнаружение несовместимых версий одного человека.
5. Инфраструктура обслуживает твою экспансию.
6. Ресурсы относятся к герою, не к рейтингу заведения.
7. До появления дублей UI/события не предполагают их существования.
8. После 100% связи уникалка остаётся в мире (постоянная орбита).
9. Автоматика использует знания; ручное наблюдение остаётся смыслом.
10. Игра одиночная; Twitch — только необязательные имена.

Подробнее: [02_LORE_RULES.md](02_LORE_RULES.md).

## 5. Ресурсы

| Ресурс | Роль |
|--------|------|
| Деньги | Подарки, одежда, персонал, дубли, проекты |
| Популярность | Тиры, стадии, контакты, финал |
| Связь (bond) | 0–100% на уникалку → постоянная орбита |
| Внимание | Лимит личного участия |
| Скандал | Краткосрочная публичная температура (может кормить ⭐) |
| **Целостность легенды** | Структурное доверие, что ты один; отдельно от скандала |

## 6. Как играется (петля)

1. FPS: готовишь, встречаешь, устраняешь сбои.
2. Ручное свидание: **наблюдение → выбор реплики (гипотеза) → реакция → журнал**.
3. Подтверждённые черты питают автоматику и дублей.
4. Bond → 100% = постоянная орбита (бонус + присутствие в мире, не удаление).
5. Дубли: сцена создания, личная приёмка, дефекты с последствиями.
6. Пространственные кризисы при росте масштаба / падении легенды.
7. Финал: Алгоритм Любви + кризисы + ручное свидание → титры → постгейм.

## 7. Черты (целевая модель)

Семь осей: пунктуальность, внимание, щедрость, азарт, спокойствие, амбиции, юмор.  
Состояния знания: неизвестно → наблюдение (факт) → гипотеза → подтверждённая черта.  
Игра фиксирует факты; **вывод делает игрок** выбором реплики. Знание ≠ симпатия.

Подробнее: [06_TRAITS_AND_BOND.md](06_TRAITS_AND_BOND.md).  
*В коде сейчас упрощённая модель correct/neutral/wrong — см. разрыв в 06.*

## 8. Дубли и легенда

- Первый дубль — стадийное событие с осмотром, не кнопка `+1`.
- Дефекты (время, внешность, память, поведение) → связанные события в мире.
- Целостность легенды падает от несовпадений; низкая легенда учащает кризисы.
- Скандал может быть выгоден при высокой легенде.

Подробнее: [07_CLONES_AND_LEGEND.md](07_CLONES_AND_LEGEND.md).

## 10. Уникальные девушки

12 якорей легенды (соседка → … → учёная → инопланетянка → Алгоритм Любви). Каждая: тир, черты, правило, бонус на орбите, позднее событие.  
Каталог: [10_CONTENT_CATALOG.md](10_CONTENT_CATALOG.md).

## 11. Качество презентации

Временные 3D-модели допустимы. Недопустимы: стандартный UI, мгновенный спавн, пустые коробки вместо помещений, системы «только кнопкой», финал без постановки.  
Чеклист: [09_PRESENTATION_QA.md](09_PRESENTATION_QA.md). Токены: [ART_DIRECTION.md](ART_DIRECTION.md).

## 12. Чего игра сознательно избегает

- Меню «выбери клона для клиентки»
- Девушка, которая знает про копии и выбирает между ними
- События/UI про дублей до их появления
- Подсказки названий черт на кнопках (после обучения)
- Открытый город, вождение, PvP, сетевые профили
