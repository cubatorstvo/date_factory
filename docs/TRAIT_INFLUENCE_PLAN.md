**Вердикт:** за одну сессию полная реализация невозможна (8 деревьев × пороги/ветки/доктрины + синергии + поиск + мир + UI + уникалки). Ниже — жёсткий порядок этапов **T0→T8**. Не помечать VERIFIED на заглушках.

---

## Разрыв «сейчас → цель»

| Сейчас в коде | Цель (11) |
|---------------|-----------|
| У уникалок `effects` / `bonus_desc` — личные пассивки в `active_effects()` | Бонусы у **деревьев черт**, не у случайной пассивки девушки |
| У массовых: likes/dislikes + traits-оси, нет 2 основных черт влияния | 2 основные черты + 1 личная особенность |
| Орбита (claimed) даёт эффекты из ContentDB.girl | Единица влияния только при **подтверждённой черте + 100% bond** |
| Нет счётчиков влияния / веток / синергий / поиска по чертам | Пороги 1/3/10/30/100/300, ветки, ограниченные синергии, вероятностный поиск |
| 7 осей в `traits_content` | 8 влияющих черт: экономность ↔ щедрость как полюса трат |

### T1 — Модель данных и пересчёт влияния ✅ VERIFIED
**Цель:** единицы влияния без UI деревьев.

- [x] `modules/girls/trait_influence_api.gd` (`TraitInfluenceAPI`) — счётчики по 8 чертам  
- [x] При claimed + confirmed trait → +1 (идемпотентно на id); `recount` из claim / reveal / load  
- [x] Save/load ключ `trait_influence` в `Game.to_dict` / `from_dict`  
- [x] `GirlsAPI.active_effects()` — только ContentDB-уникалки; city/mass не суммируют `effects`  
- [x] Toast при пересечении порога: «Влияние «…»: N девуш. (порог K)»  
- [x] До T2: вклад = confirmed оси из `girl_traits` (маппинг; `generosity`→`generous`; `thrift` через `primary_traits` или id)

**Приёмка:** compile clean; editor smoke API; wiring claim/reveal/save. Live `exec` на Game блокирован отсутствием GodotIQ runtime attach — пересчёт покрыт идемпотентной логикой + reconcile на load.

### T2 — Две черты + особенность у массовых ✅ VERIFIED
**Цель:** генерация/контент города и кандидаток.

- [x] Массовая: `primary_traits: [A, B]`, `quirk` (`TraitsContent.pack_for_profile`, city/proc/unlock)  
- [x] Сигналы: диалоги по dialogue-ключам primary; thrift — 3 карты; generosity↔thrift как полюса  
- [x] Уникалки: пары §22 в `ContentPacks.girls` + quirk / author `bonus_desc`  
- [x] Массовые без random passive bonus; на свидании показывается quirk  

**Приёмка:** editor smoke — neighbor attentive+calm; business thrift+ambitious; 40× pick без thrift+generous; thrift_cards=3.

### T3 — Пороги 1 и 3 + авто-правила ✅ VERIFIED
**Цель:** ранний смысл системы.

- [x] Порог 1 thrift: −10% цена подарка экономным; разумный подарок сильнее, пустой люкс слабее  
- [x] Порог 1 punctual/calm: бонус prep у «порядка»; меньше скандала у спокойных  
- [x] Порог 3 thrift: авто избегает empty luxury; search* флаг; бонус авто-confidence  
- [x] Телефон: вкладка **Orbit** — счётчики `N/next` и уроки/авто  

**Приёмка:** editor smoke thrift@3 → `3/10`, `auto_avoid_empty_luxury`, phone report.

### T4 — Порог 10: выбор ветки (3 направления) ✅ VERIFIED
**Цель:** первая стратегия.

- UI выбора ветки A/B/C для каждой черты при достижении 10  
- Сохранение выбранной ветки; нельзя получить все три сразу  
- Минимальные эффекты веток (по одному правилу на ветку, не полный каталог %)  
- Превью последствий до выбора (§7.2)

**Приёмка:** thrift@10 → выбор; эффекты A≠B; смена ветки недоступна или дорогая (заглушка политики).  
**Сделано:** `BRANCH_DEFS` + `choose_branch` / save `branches`; thrift A gift −8% / B staff −8% / C fail refund 35%; stubs в `branch_passive_effects`; Orbit PickRow A/B/C + preview tooltips; политика «смена недоступна».

### T5 — Порог 30 + синергии (слоты) ✅ VERIFIED
**Цель:** специализация + комбо.

- Углубление / открытие второй ветки  
- Синергии из §18 при min 30/30; слот с stage_3  
- Активных синергий ограничено (1 → больше на поздних стадиях)  
- Авторские синергии уникалок — хуки, не обязательно полный контент

**Приёмка:** нельзя активировать все синергии сразу; «Точный подарок» (thrift+attentive) меняет правило выбора подарка.  
**Сделано:** `depth_choices` deepen/expand; `SYNERGY_DEFS` (6 шт.) + слоты 1/2/3 по stage; `precise_gift` → `pick_precise_gift` в авто; Orbit DepthRow/SynRow; save `active_synergies`.

### T6 — Поиск кандидаток по чертам ✅ VERIFIED
**Цель:** стратегия набора орбиты.

- Цель поиска: черта или пара черт  
- Повышает вероятность спавна/встречи, не гарантирует тег  
- Ложноположительные случаи; подтверждение всё ещё руками  
- Точность растёт с влиянием (§20.3)

**Приёмка:** поиск thrift чаще даёт thrift-сигналы; метки «экономная» над головой нет.  
**Сделано:** `search_targets` + accuracy; `roll_search_profile` → proc/city; soft_signal в Candidates (не имя черты); Orbit SearchRow; save.

### T7 — Пороги 100 / 300, мир, уникалки, финал ✅ VERIFIED

## Нельзя «додумать» (из §32)

Случайные пассивки массовых · влияние без подтверждения и 100% · >1 единицы с одной девушки на черту · авто-открытие всех веток · синергия = сумма % · авто знает неизвестное · уникалка = несколько единиц влияния · прогресс только в меню без мира.
