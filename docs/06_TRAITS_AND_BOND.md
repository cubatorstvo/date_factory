# 06 — Наблюдения, гипотезы, черты и связь

## Фантазия
Свидание — не угадайка тегов и не меню клонов. Ты наблюдаешь поведение, интерпретируешь, проверяешь ответом и строишь профиль. Дубли и автоматика используют только записанные знания.

> **Игра фиксирует факты, но не делает вывод за игрока. Выбранная реплика — практическая гипотеза.**

## Семь осей
`time` пунктуальность · `attention` внимание · `generosity` щедрость · `adventure` азарт · `peace` спокойствие · `ambition` амбиции · `humor` юмор.

Черта = ось + выраженность + отношение к поведению + сигналы + проверки + влияние на подарок/место/реплики + эффект на авто.

## Тиры
| Тир | Черт | Сигналы | Награда | Смысл |
|-----|------|---------|---------|--------|
| simple | 3 | Очевидные | ×1.0 | Обучение, быстрый прогресс |
| medium | 5 | Менее прямые + правило | ×1.45 | Нужно изучение |
| high | 7 | Сложные / противоречивые | ×2.1 | Часть знаний не только диалогом; риск легенде |

Тир ≠ «больше тех же кликов».

## Состояния знания

### Неизвестно
`???`. Авто действует по шаблону. Нет рекомендаций.

### Наблюдение
Автоматически записанный **факт** естественным языком («Пришла на 20 минут раньше»), без названия черты.  
Появляется: до реплики, на входе, при реакции на подарок, в событии, при встрече в комплексе.

### Гипотеза
Фиксируется, когда игрок выбирает реплику/действие со **скрытой интерпретацией**.  
Совпала с реальной чертой → «Похоже, для неё важно …» (ещё не финал).  
Не совпала → гипотеза опровергнута; правильная черта **не** раскрывается бесплатно; факт остаётся в журнале.

У реплики одна интерпретация. Три почти одинаковых ответа запрещены.

### Подтверждённая черта
Один из путей:
1. Дважды правильно интерпретированы **разные** наблюдения одной оси.
2. Правильная гипотеза + прямое личное событие.
3. Явная формулировка девушки при достаточном bond.
4. Insight-проверка только после ≥1 наблюдения.

После подтверждения: название, краткое описание, точные рекомендации автоматике, прогноз подарков/мест.

## Оценка ответа (два слоя)
1. **Интерпретация:** совпала / частично / нет.
2. **Качество поведения:** удачное / допустимое / неудачное.

Можно верно понять черту и грубо ответить → знание растёт, связь падает.  
Знание и симпатия — разные величины.

Ориентиры bond (0–100): идеал +12…16; верная гипотеза средне +6…9; вежливо нейтрально +1…4; неверное чтение мягко −2…6; плохой ответ −8…14; особое событие +10…20; удар по легенде — отдельно.

## Структура ручного свидания
1. Подготовка (место/одежда/подарок; прогноз только по подтверждённому).
2. Приход (физический; первый сигнал).
3. Ситуация 1 — социальный сигнал + 3 интерпретации.
4. Ситуация 2 — подарок/место.
5. Ситуация 3 — неожиданность мира.
6. Завершение: итог, журнал, презентация новой подтверждённой черты, уход.

## Журнал в телефоне
- Факты  
- Гипотезы (активная / подтверждённая / опровергнутая) + ссылка на факт  
- Подтверждённые черты  
- История ключевых реакций  
- Уверенность автоматики: низкая / средняя / высокая / полная  

## Автоматические свидания
Качество = знания + апгрейды + качество дубля + легенда.  
Мало наблюдений → импровизация; гипотезы → риск; подтверждённые → стабильность; полный профиль → почти идеал.  
Режимы: осторожный / стандартный / рискованный.  
Автосвидание должно быть **видимо** в зале (не только таймер).

## Постоянная орбита (100%)
1. Постановочное завершение.  
2. Обычный гринд связи прекращается.  
3. Заселение / постоянная точка в комплексе.  
4. **Вклад в коллективное влияние подтверждённых черт** (не случайная личная пассивка) — см. [11_TRAIT_INFLUENCE.md](11_TRAIT_INFLUENCE.md).  
5. Наряды и личные подарки.  
6. Раздел поздних событий.  
7. Участие в кризисах и финале.  

Нельзя просто убрать персонажа в список.

> **Канон бонусов орбиты:** бонусы принадлежат изученным чертам и деревьям влияния (пороги 1/3/10/30/100/300, ветки, синергии, доктрины). Уникалки модифицируют знакомые деревья авторски. План внедрения: [TRAIT_INFLUENCE_PLAN.md](TRAIT_INFLUENCE_PLAN.md).

## Обучение
Первое свидание: очевидное наблюдение, различимые реплики, объяснение гипотезы, второе подтверждение → черта, намёк что авто берёт только знания.  
После обучения названия черт на кнопках не показывать.  
Опционально: помощь полная / стандарт / минимум.

## Контент (минимум)
На черту ≥2 разных наблюдения; ≥3 ситуации первого свидания; набор повторных; ≥1 позднее событие на уникалку.  
Каталог: `core/traits_content.gd` (текущий) → расширять под наблюдения/интерпретации.  
Логика цель: `GirlsAPI` + `DatingAPI` + журнал в phone UI.
